Cards & chips

Cards use container-tone tags instead of bare brand colors — softer, and it keeps the loud primary red reserved for real actions. Chips work well for filters, tags, or "Ask a question" style prompts. Below that, the filled versions in solid red and blue are the "stand out" option — reach for those only when something genuinely needs to win the most attention on a page.

Components

Accordion

Good for FAQs or a long usage-rules list where most people only need one answer — collapsed by default so the page doesn't feel overwhelming. Click a question.

Can I use the logo with the tagline on a flyer?▾
Only if the piece is short-lived (an event, an award, a single campaign). The tagline changes over time with district goals, so anything meant to last — policy documents, signage, letterhead — should use the logo without it.
What file do I use for a dark background?▾
Use the reversed white logo file from the library, not the full-color version with a box behind it. Full color is built for light backgrounds only.
Can I recolor the logo to match a flyer?▾
No — only the approved full-color and all-white versions are ever used. Never apply a different brand's colors, a gradient, or a one-off hue.
