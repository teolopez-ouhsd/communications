Communications & Marketing Hub

The district's central resource for staying on-brand and on-message — logos, colors, tools, and standards for anyone creating materials for OUHSD or a school site.

Why this exists

One place, instead of a dozen old files

This hub exists so that anyone creating something public-facing for the district — a flyer, an email, a school site page, a social post — can find the current logo, the right colors, and the correct rules in one place, instead of reusing an old template, guessing, or waiting on a request to the communications team.

It's built specifically for the people doing this work at the site level: webmasters, social media reps, front office staff, and anyone else producing public-facing content. That includes school site web pages — this is where to pull the current logo files, colors, and content standards so every school builds from the same foundation instead of drifting from it.

This hub will grow over time. What's below reflects what's available today and what's coming next as more resources are built and rolled out.
